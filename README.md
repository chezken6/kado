# Retro Game Console

Proyek "Retro Game Console" adalah sebuah aplikasi berbasis web yang menghadirkan pengalaman bermain game retro, mendengarkan musik, dan melihat galeri gambar.

## Fitur Utama

- **Game Retro:** Nikmati permainan klasik seperti Snake dan Tetris.
- **Pemutar Musik:** Dengarkan koleksi musik yang tersedia.
- **Galeri Gambar:** Jelajahi berbagai gambar dalam galeri.
- **Navigasi Mudah:** Antarmuka yang intuitif untuk menjelajahi berbagai bagian konsol.

## Struktur Proyek

- `index.html`: Halaman utama konsol.
- `pages/`: Berisi halaman-halaman spesifik seperti game, musik, galeri, dll.
- `music/`: Folder untuk file musik.
- `sounds/`: Folder untuk efek suara.
- `images/`: Folder untuk gambar galeri.
- `script.js`: Logika JavaScript untuk interaktivitas.
- `style.css`: Styling untuk tampilan konsol.

## Cara Menggunakan

Buka file `index.html` di browser web Anda untuk memulai.
